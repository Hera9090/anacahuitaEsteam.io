Anacahuita E-STEAM 
Ideas que transforman nuestro territorio.
Anacahuita E-STEAM es una iniciativa orientada al desarrollo de experiencias educativas que integran ciencia, tecnología, ingeniería, artes y matemáticas (STEAM) con el ambiente, el cambio climático y la ética biocultural.
El proyecto busca acercar herramientas de aprendizaje, experimentación y creación tecnológica a comunidades y organizaciones socioambientales, promoviendo soluciones contextualizadas a los desafíos de sus territorios.
Objetivo
Desarrollar y compartir experiencias educativas E-STEAM que fortalezcan las capacidades de niñas, jóvenes, docentes y comunidades para comprender y atender problemáticas socioambientales.
¿Qué encontrarás aquí?
    • Proyectos: iniciativas y experiencias E-STEAM vinculadas con el territorio.
    • Retos: actividades para explorar y resolver problemas ambientales.
    • Inspiración: ideas, experiencias y propuestas para aprender creando.
    • Materiales: recursos educativos descargables y adaptables.
    • Cuentos: materiales narrativos para explorar la relación entre sociedad y naturaleza.
Enfoque
La propuesta integra:
    • Educación STEAM.
    • Cambio climático y educación ambiental.
    • Ética biocultural.
    • Perspectiva de género.
    • Alfabetización digital.
    • Programación y robótica accesible.
Estado del proyecto
Actualmente, Anacahuita E-STEAM se encuentra en etapa de desarrollo y construcción de su plataforma digital.
Tecnologías
    • HTML
    • CSS
    • JavaScript
    • GitHub Pages
Este proyecto se encuentra en desarrollo. Los términos de uso y distribución de sus materiales se definirán posteriormente.
